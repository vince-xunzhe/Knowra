# 索骥 / Domain

索骥是本地桌面端的论文研究画布。主导航位于「回顾」与「推荐」之间。领域继承系统的论文大类（包括自定义大类和「其他」），每个领域有一张无限画布，也可额外创建独立领域。用户可手动整理，也可点击「agent代连」生成有证据的关系与布局预览；画布不会创建论文库记录。

## 使用

1. 在主导航打开「索骥」，通过顶部「领域」下拉菜单切换大类，选项仅显示领域名称，右侧「已导入」独立显示当前画布的论文卡片数量；旁边的加号可新建独立领域。
2. 点击「导入论文」，搜索标题或年份、按分类筛选，然后批量选择。第一次导入按年份布局；后续导入避开已有内容，必要时平移视野以展示新引用。
3. 拖动卡片整理脉络，点击一张卡片的「连线」，再点击目标卡片。选择连线，在右侧编辑说明或使用关系标签。
4. 选择卡片，在右侧填写附属备注；文字工具创建独立文本。选中若干卡片或文本后创建分组可将它们一起收纳，也可通过「所属分组」调整成员。
5. 卡片绿色「+」显示论文回顾中的核心贡献、摘要、研究问题和研究动机。浮层跟随卡片和视野移动，缺少内容的页签为空。可打开完整回顾，然后返回原领域、视野与选中卡片。

画布与右侧研究工作区之间的分隔线可左右拖动，宽度保存在本机。双击恢复默认；聚焦分隔线后可用左右方向键微调，Home/End 调至最小/最大宽度。窗口变窄时自动限制面板宽度，保留画布操作空间；生成或预览期间仍可调整。

支持框选、Shift 多选、空格拖动/手形工具平移、滚轮平移、Ctrl/Cmd + 滚轮缩放、适应画布、搜索定位、锁定元素、分组缩放，以及撤销/重做（Ctrl/Cmd+Z、Ctrl/Cmd+Shift+Z）。撤销记录最多保留最近 100 次操作，切换页面时保留，重启后不恢复。

删除卡片只移除该引用、其附属备注和连接它的线；删除分组框保留其内部元素。继承的大类在知识页统一管理；独立领域可重命名、排序和删除，删除需要确认，不会删除论文库记录。系统大类重命名会保留画布 ID 与编辑；大类被删除时，有内容的画布保留为独立领域，空画布移除。旧版 LLM 画布原地继承分类；旧「三维重建」画布有内容则保留，空画布由静态/动态大类替代。分组为单层结构，允许跨组连接。同一篇论文可在不同领域或同一画布重复引用，各实例的布局、分组和备注独立。

## 数据与导入约束

- 卡片完整展示标题与年份，不显示作者。未知年份明确显示「年份未知」。
- 浮层直接读取论文回顾同源字段：`core_contribution`、`abstract_summary`、`problem`、`motivation`，使用现有抽取解析器兼容旧响应。
- 新引用须对应已有、已处理的论文，回顾可解析且四项至少一项有有效正文。前端置灰不符合条件的论文，后端再次检查；不允许绕过选择器新建任意论文节点。
- 回顾后来不完整或重新处理时，已有实例与所有编辑成果保留；新的导入仍需重新满足条件。
- 论文去重合并时，画布引用与已准入实例登记同步转向保留的论文 ID，布局与备注不受影响。

## 本地存储与并发

`domain_workspace` 是 SQLite 本地表，由现有 `Base.metadata.create_all` 启动预检创建，不修改论文表或现有图谱。它保存一个有版本号的工作区快照：有序领域、活动领域、各领域的视野、节点、连线，以及已准入论文实例登记。最后一项允许撤销删除的旧引用，即使其回顾后来不完整，也不会放开新引用的导入限制。

本地接口仅在桌面模式挂载：

- `GET /api/domains`：读取快照并同步系统大类，按系统大类顺序排列，独立领域随后展示。
- `PUT /api/domains`：验证快照结构与新论文引用，以 `revision` 条件更新；冲突返回 409。
- `GET /api/domains/papers`：列出用于导入和浮层的轻量论文回顾信息，不加载 PDF 全文或聊天记录。

前端编辑后延迟 650 ms 自动保存，通过串行队列避免较早请求覆盖较新编辑。保存失败保留内存中的编辑，允许重试；多窗口冲突不会自动覆盖，用户确认后可重新加载本机版本。存在未保存内容时浏览器离页会提示。论文回顾在进入页面、窗口重新聚焦和页面活动期间每 30 秒刷新；已保存的画布同时检查分类变更，不覆盖正在编辑的内容。收到外部版本后清空旧版本的撤销历史。

本版本不加入云同步协议，不提供多人协作。未提交到后端的内容依赖当前页面会话，强制终止进程仍可能丢失待保存修改。

## 验证

- 后端：`pytest -q backend/tests/test_domains.py backend/tests/test_paper_dedupe_service.py`。
- 浏览器：在 `frontend` 中运行 `npx playwright test tests/domain.spec.ts tests/appearance.spec.ts`。

浏览器测试使用模拟论文；后端 API 测试使用隔离 SQLite 数据库。测试不需要修改用户真实论文或生产配置。


## Agent 代连

每个类别的画布左上角提供「agent代连」，至少导入两篇不同论文后可用。它只分析当前画布已导入的论文，不补导论文。设置页的「索骥代连」独立配置模型与推理强度；首次默认继承论文抽取模型。

1. 点击连线中点的小锁，锁定需要保护的连线；灰蓝色开锁表示未锁定，琥珀色闭锁表示已锁定，再次点击可解锁。小锁随连线移动并保持固定屏幕尺寸，生成/预览期间禁用。生成保留所有锁定连线的方向、端点、标签；其余连线（包括手动创建的）参与替换。锁线不冻结卡片位置。
2. 生成时逐页读取本地 PDF，包括末尾参考文献；结合完整结构化回顾和对应论文 Wiki，检索相关片段分批送给模型。不联网，不执行 OCR；缺失或不可读的材料显示在预览提示里。Wiki 与回顾不视为独立佐证。
3. 关系分为基于、改进、借鉴、对比、引用，并区分原文明示与 AI 推断。箭头由基础/被引用工作指向后续工作；每条连线必须有可在输入材料中核对的引文。仅主题相近不会要求连线，无证据的论文保持独立。
4. 生成完显示方案预览、替换数量、保护数量、材料提示和未连接论文。选中线查看理由、出处、引文和 PDF 物理页码。「应用方案」一次写入当前类别，可整体撤销；「放弃方案」保留原画布。
5. 生成与预览期间当前类别只能浏览、平移缩放、查看回顾，其他类别仍可编辑。可取消生成；已经发送的模型调用可能仍会完成，但其结果不会应用。切换页面、刷新后任务和预览仍保留；失败或 worker 中断会恢复编辑，可重新生成。

布局以关系的左右层级为主，年份用于稳定排序，分支上下展开；保留锁定卡片/分组的位置、分组成员关系、卡片备注和独立文本。含锁定成员的分组不会整体移动。重复论文只分析一次，通常每对论文只生成一条线，优先同组、再选当前位置最近的实例；已有锁定的重复连线均保留。

### 持久化与接口

`domain_agent_runs` 保存目标类别快照、任务 ID、状态与预览，`tasks.db` 的 durable worker 保存进度和检查点。生成不会修改 `domain_workspace`；应用在事务中比较原节点/连线、更新目标类别并递增版本，保留其他类别与视野。普通保存接口也会检查生成/预览期间的只读约束，防止其他窗口绕过。后台通用「恢复」不复用旧画布快照，需回到索骥重新生成。

- `GET /api/domains/agent/runs`：每个类别最近的任务状态和可用预览。
- `POST /api/domains/agent/runs`：提交 `boardId`、当前 `revision`、可选卡片实测 `heights`。
- `POST /api/domains/agent/runs/{id}/discard`：取消生成或丢弃预览。
- `POST /api/domains/agent/runs/{id}/apply`：应用方案，返回新工作区及目标类别的应用前快照，供一次撤销。

### 范围与验证限制

逐页读取不等于把全文放进每次调用：使用片段检索控制上下文，每篇焦点论文与至多 8 篇候选分批分析，覆盖当前类别全部论文对。论文数量增加时调用量近似平方增长；使用已配置的模型服务，按该服务计费。引文校验能排除编造出处和不在材料中的句子，不能证明模型对学术关系的理解正确，仍需用户审阅。低质量扫描 PDF、检索遗漏和模型能力都可能造成漏连。

新增验证：`backend/.venv/bin/python -m pytest -q backend/tests/test_domain_agent.py` 和 `cd frontend && npx playwright test tests/domain.spec.ts`。使用隔离数据库、合成材料与模拟模型输出，覆盖证据校验、末页参考文献、锁定保护、跨窗口只读、取消/失败、预览、应用/撤销，不用用户论文评测模型语义准确率。


### 引用语境深读

代连先匹配参考文献中的完整标题，再沿编号（含并列引用和区间）、作者年份、方法/模型名称查找正文。读取引用附近的上下文；如果段落延伸到下一物理页，也提供下一页开头。正文与参考文献分开标记，同一页混排及参考文献后的附录也分别处理。

对有正文线索的关系增加一次模型深读，按「引用用途」「作者评价」「与本文的异同」提炼作者自己的观点。每项观点单独验证引文与页码，只接受来自引用论文正文的证据；没有明确评价则留空，不把模型自己的比较写成作者观点。并列引用保留集体归因。仅有参考文献时保留引用关系并说明未找到正文语境，不据此升级成继承或改进。

每对论文最多选取 12 处正文语境、2 个参考条目；优先覆盖不同页面，界面显示定位数、实际分析数及截取提示。复杂 PDF 排版、未识别引用格式、跨页参考条目或扫描件仍可能漏检，模型的语义转述仍需审阅。现有画布不会自动重写：重新「agent代连」并应用后才获得新分析，锁定连线继续保留原样。

回归记录：5 种合成引用样例（单编号、并列编号、编号区间、作者年份、方法名）的正文语境召回从标题检索基线 0/5 提升到 5/5；另测了编号误匹配、相近模型版本、并列参考条目、正文/参考文献边界、下一页延续、证据造假及只找到参考文献的场景。该结果不代表真实论文观点提取准确率。测试命令：`backend/.venv/bin/python -m pytest -q backend/tests/test_domain_citations.py`。

连线详情将关系解读与证据分开呈现。解读旁的证据编号可展开并定位到统一的「证据与出处」列表；同一论文、同一来源、同一页的摘录合并展示，重复摘录去重，不同摘录保留。每个出处标明支持的解读项，默认折叠；无正文深读数据的旧连线仍可查看其连线依据。
