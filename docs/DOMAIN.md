# 索骥 / Domain

索骥是本地桌面端的论文研究画布。主导航位于「回顾」与「推荐」之间。领域继承系统的论文大类（包括自定义大类和「其他」），每个领域有一张无限画布，也可额外创建独立领域。画布不会自动推断学术关系，也不会创建论文库记录。

## 使用

1. 在主导航打开「索骥」，选择或创建领域。
2. 点击「导入论文」，搜索标题或年份、按分类筛选，然后批量选择。第一次导入按年份布局；后续导入避开已有内容，必要时平移视野以展示新引用。
3. 拖动卡片整理脉络，点击一张卡片的「连线」，再点击目标卡片。选择连线，在右侧编辑说明或使用关系标签。
4. 选择卡片，在右侧填写附属备注；文字工具创建独立文本。选中若干卡片或文本后创建分组可将它们一起收纳，也可通过「所属分组」调整成员。
5. 卡片绿色「+」显示论文回顾中的核心贡献、摘要、研究问题和研究动机。浮层跟随卡片和视野移动，缺少内容的页签为空。可打开完整回顾，然后返回原领域、视野与选中卡片。

支持框选、Shift 多选、空格拖动/手形工具平移、滚轮平移、Ctrl/Cmd + 滚轮缩放、适应画布、搜索定位、锁定元素、分组缩放，以及撤销/重做（Ctrl/Cmd+Z、Ctrl/Cmd+Shift+Z）。撤销记录最多保留最近 100 次操作，切换页面时保留，重启后不恢复。

删除卡片只移除该引用、其附属备注和连接它的线；删除分组框保留其内部元素。继承的大类在知识页统一管理；独立领域可重命名、排序和删除，删除需要确认，不会删除论文库记录。系统大类重命名会保留画布 ID 与编辑；大类被删除时，有内容的画布保留为独立领域，空画布移除。旧版 LLM 画布原地继承分类；旧「三维重建」画布有内容则保留，空画布由静态/动态大类替代。分组为单层结构，允许跨组连接。同一篇论文可在不同领域或同一画布重复引用，各实例的布局、分组和备注独立。

## 数据与导入约束

- 卡片完整展示标题与年份，不显示作者。未知年份明确显示「年份未知」。
- 浮层直接读取论文回顾同源字段：`core_contribution`、`abstract_summary`、`problem`、`motivation`，使用现有抽取解析器兼容旧响应。
- 新引用须对应已有、已处理的论文，回顾可解析且四项至少一项有有效正文。前端置灰不符合条件的论文，后端再次检查；不允许绕过选择器新建任意论文节点。
- 回顾后来不完整或重新处理时，已有实例与所有编辑成果保留；新的导入仍需重新满足条件。
- 论文去重合并时，画布引用与已准入实例登记同步转向保留的论文 ID，布局与备注不受影响。

## 本地存储与并发

`domain_workspace` 是 SQLite 本地表，由现有 `Base.metadata.create_all` 启动预检创建，不修改论文表或现有图谱。它保存一个有版本号的工作区快照：有序领域、活动领域、各领域的视野、节点、连线，以及已准入论文实例登记。最后一项允许撤销删除的旧引用，即使其回顾后来不完整，也不会放开新引用的导入限制。

本地接口仅在桌面模式挂载：

- `GET /api/domains`：读取快照并同步系统大类，按系统大类顺序排列，独立领域随后展示。
- `PUT /api/domains`：验证快照结构与新论文引用，以 `revision` 条件更新；冲突返回 409。
- `GET /api/domains/papers`：列出用于导入和浮层的轻量论文回顾信息，不加载 PDF 全文或聊天记录。

前端编辑后延迟 650 ms 自动保存，通过串行队列避免较早请求覆盖较新编辑。保存失败保留内存中的编辑，允许重试；多窗口冲突不会自动覆盖，用户确认后可重新加载本机版本。存在未保存内容时浏览器离页会提示。论文回顾在进入页面、窗口重新聚焦和页面活动期间每 30 秒刷新；已保存的画布同时检查分类变更，不覆盖正在编辑的内容。收到外部版本后清空旧版本的撤销历史。

本版本不加入云同步协议，不提供多人协作。未提交到后端的内容依赖当前页面会话，强制终止进程仍可能丢失待保存修改。

## 验证

- 后端：`pytest -q backend/tests/test_domains.py backend/tests/test_paper_dedupe_service.py`。
- 浏览器：在 `frontend` 中运行 `npx playwright test tests/domain.spec.ts tests/appearance.spec.ts`。
- 前端构建：在 `frontend` 中运行 `npm run build`。

浏览器测试使用模拟论文；后端 API 测试使用隔离 SQLite 数据库。测试不需要修改用户真实论文或生产配置。
